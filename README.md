# Лабораторная работа №4. Написание Unit-тестов

## Архитектура проекта

Проект `geometric_lib` организован по модульному принципу: каждая геометрическая фигура вынесена в отдельный файл, содержащий функции вычисления площади (`area`) и периметра (`perimeter`).

```text
geometric_lib/
├── docs/                  # Документация проекта
│   └── README.md
├── circle.py              # Функции area(r) и perimeter(r) для круга
├── rectangle.py           # Функции area(a, b) и perimeter(a, b) для прямоугольника
├── square.py              # Функции area(a) и perimeter(a) для квадрата
├── triangle.py            # Функции area(a, h) и perimeter(a, b, c) для треугольника
└── test_geometry.py       # Модульные тесты (unittest)
```

## Запуск тестов

Для запуска всех модульных тестов выполните команду из корневой директории проекта:

```bash
python -m unittest test_geometry.py
```

Ожидаемый вывод в терминале:

```text
.............
----------------------------------------------------------------------
Ran 13 tests in 0.001s

OK
```

## План тестирования

### 1. Цели и задачи тестирования

* **Цель тестирования:** проверить корректность работы функций вычисления площади и периметра геометрических фигур в библиотеке `geometric_lib` и автоматизировать регрессионную проверку при изменении исходного кода.
* **Задачи тестирования:**
  * определить наборы тестовых входных данных (типовые и граничные значения);
  * выполнить предварительный ручной расчет эталонных результатов;
  * разработать автоматизированные unit-тесты на базе встроенного модуля `unittest`;
  * зафиксировать результаты выполнения тестов и отразить добавление тестового модуля в истории репозитория GitHub.

### 2. Описание тестируемого продукта

Тестируемый продукт — библиотека `geometric_lib` на языке Python, предназначенная для расчета основных геометрических характеристик плоских фигур.

**Основные функциональные требования:**
* вычисление площади (`area`) и периметра (`perimeter`) для прямоугольника, квадрата, круга и треугольника;
* корректная работа при передаче положительных целочисленных и вещественных значений;
* корректная обработка граничных нулевых значений аргументов;
* соблюдение математической точности вычислений с использованием константы `math.pi`.

### 3. Область тестирования

В область тестирования входят следующие модули и функции:
* `rectangle.py`: `area(a, b)`, `perimeter(a, b)`
* `square.py`: `area(a)`, `perimeter(a)`
* `circle.py`: `area(r)`, `perimeter(r)`
* `triangle.py`: `area(a, h)`, `perimeter(a, b, c)`

### 4. Стратегия тестирования

* **Уровень тестирования:** модульное (Unit-тестирование) — каждая функция проверяется изолированно.
* **Подход к тестированию:** тестирование методом «белого ящика» (структура кода и используемые формулы известны).
* **Техники тест-дизайна:** эквивалентное разбиение (стандартные положительные значения сторон/радиуса) и анализ граничных значений (нулевые значения параметров).
* **Инструментарий:** стандартная библиотека `unittest` (Python 3), система контроля версий Git и хостинг репозиториев GitHub.
